# Liquid Drop Gallery

Interactive WebGL recreation of Ümit Çelik's liquid-frame photo gallery.

Open the live page: https://yrzhe.github.io/liquid-drop-gallery/

- Tap or click a drop to bring it into the frame
- Drag the frame edge for a jelly pull
- Tap empty space to add a drop
- Use the pencil button for goo, bounce, orbit and refraction
