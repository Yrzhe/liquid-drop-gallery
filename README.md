# Liquid Drop Gallery

Interactive WebGL recreation of Ümit Çelik's liquid-frame photo gallery, matched frame by frame against the original clip.

Open the live page: https://yrzhe.github.io/liquid-drop-gallery/

- Click or tap a drop to bring it into the frame (the ring of drops shifts one slot per step)
- Scroll or use the arrow keys to step through the six photos
- Drag the frame edge to pull out a liquid tentacle
- Click empty space to add a drop
- Use the pencil button for goo, bounce, drift, refraction and crop guides

Add `?demo` to the URL to play the scripted demo that follows the original video's timeline.
